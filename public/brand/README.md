# LOOP provisional brand kit

Three original directions are provided. `01-common-ground` is the website's provisional mark; `02-open-embrace` and `03-forward-path` are alternatives. SVG is the editable master. PNG variants use real transparent alpha, not a checkerboard baked into the image. Black, white and ink color versions are supplied.

The outlined wordmark contains geometry, not embedded font files. The website's live wordmark uses its configured web typography. The wordmark explorations are alternatives, not a claim to reproduce an existing approved LOOP identity.

`favicon.svg` and the PNG/ICO assets are simplified for small sizes. The Apple touch icon has an intentional opaque paper background; ordinary logo PNGs remain transparent. Do not use the detailed organization subtitle in a favicon. Test the SVG favicon in light/dark browser chrome on the actual domain.

These concepts are provisional and require owner approval. They are not a trademark clearance, registration or claim that an existing LOOP mark has been replaced officially. No font files, third-party logo assets or demo reference images are redistributed.
